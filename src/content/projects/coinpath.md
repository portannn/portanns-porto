My own app, built with no framework, no build step and no dependencies in the shipped code. Five screens (home, budgets, trends, history, more), hand-rolled charts, recurring transactions, CSV import/export, light/dark theming, per-user Firestore security rules, and Playwright test suites for the logic and UI flows.
